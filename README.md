# SentinelAI

## Overview

SentinelAI is a disaster response multi-agent system built with
Google ADK and Gemini.

## Features

- Multi-Agent Coordination
- Google Search
- Medical Planning
- Supply Planning
- Verification Agent
- Report Agent
- PDF Generation
- Filesystem Storage
- Prompt Injection Detection
- Human Approval
- Streamlit Dashboard

## Technologies

- Python
- Google ADK
- Gemini 2.5 Flash
- Streamlit
- ReportLab

## Installation

pip install -r requirements.txt

## Run

python -m streamlit run streamlit_app.py
